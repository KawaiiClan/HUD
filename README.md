# Kawaii-HUD
### Movement mode focused client HUD with KawaiiClan colors
Modified version of [this](https://gamebanana.com/mods/22973) HUD
Background image by [Nyu](https://gamebanana.com/mods/320096)

## Install
Place kawaii-hud folder into `cstrike/custom` and launch your game
